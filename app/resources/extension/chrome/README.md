# GoAiEz Prospect Scanner Extension

## How to Load It Unpacked
1. Open Chrome and navigate to `chrome://extensions`.
2. Enable **Developer mode** (toggle in the top right).
3. Click **Load unpacked** and select this folder (`resources/extension/chrome`).

## Usage
- **Pixel key**: Copy this from Your account → Tracking inside the GoAiEz platform.
- **Connect**: Authenticates the extension using your Pixel key and stores a session token.
- **Scan this page**: Reads the current page's DOM and sends it to the platform to record a prospect scan.

Publishing to the Chrome Web Store needs a developer account; not part of this package.
