# Site fonts

The modern fonts a published site may use (`App\Modules\X103\Domain\SiteFonts`), served from this application so a
visitor's browser asks no font provider for anything. Each family is its latin subset in weights 400 and 700, downloaded
from Google Fonts on 2026-10-03.

All are licensed under the SIL Open Font License 1.1 — each family's licence and copyright line is in `OFL-<family>.txt`
beside its files. The fonts may be used, bundled and redistributed with this software; they may not be sold by themselves.
